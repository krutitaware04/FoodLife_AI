
# AI-Based Food Inventory and Waste-Risk Prediction System

## 1. Project Overview

The AI-Based Food Inventory and Waste-Risk Prediction System is a web application designed to help users manage food inventory, monitor expiry dates, predict food waste risk, and plan food consumption efficiently.

The system uses machine learning techniques and food inventory data to help users identify food items that should be consumed first and reduce unnecessary food waste.

## 2. Project Objectives

- Manage food inventory digitally.
- Track food purchase dates and expiry dates.
- Predict the risk of food wastage.
- Identify food items that should be consumed first.
- Provide food consumption and inventory insights.
- Generate shopping lists based on user requirements.
- Help administrators monitor users, products, and system analytics.
